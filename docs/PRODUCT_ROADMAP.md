# Meetly AI Intelligence — Product Roadmap

## Phase 1 — Working foundation
- Audio upload
- Whisper transcription
- Groq structured analysis
- Meeting storage
- Action items and decisions
- PDF reports

## Phase 2 — RAG memory
- Chunk transcripts and documents
- Generate embeddings
- Vector store (MongoDB Atlas Vector Search, pgvector, or another managed store)
- Retrieval with citations
- Ask-meeting-memory interface

## Phase 3 — Real-time copilot
- WebSocket event channel
- Streaming transcript chunks
- Rolling summary
- Live action/decision detection
- RAG retrieval against previous meetings

## Phase 4 — Google Meet
- Google OAuth
- Google Meet Add-on
- Workspace Events
- Meet Media API where available
- Participant and consent handling
- Live side-panel updates

## Phase 5 — Enterprise intelligence
- Team workspaces
- Roles and permissions
- Calendar context
- Slack/email/task integrations
- Audit trail
- Retention controls
- Admin analytics
